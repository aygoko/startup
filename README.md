# Лендинг стартапа

## Что это такое

**Лендинг** (landing page) — это одностраничный сайт, созданный с одной конкретной целью: превратить посетителя в целевое действие. В отличие от многостраничных сайтов, здесь нет «лишних» разделов — вся страница выстроена так, чтобы провести пользователя по логике: заинтересовать → объяснить ценность → подтолкнуть к действию.

## Зачем он нужен стартапу

- **Первое лицо проекта.** Это внешнее выражение стартапа как самостоятельной сущности — то, что увидят пользователи, инвесторы и партнёры.
- **Проверка идеи.** Лендинг заставляет сформулировать УТП коротко и ясно: если не получается — значит, идея ещё сырая.
- **Точка входа.** Он собирает трафик из соцсетей, рекламы, презентаций и ведёт к конкретному действию: заявке, подписке, звонку, переходу в Telegram.
- **Обратная связь.** По конверсии видно, что работает, а что нет — без больших затрат на разработку.

## Из чего состоит

Классический лендинг строится по проверенной схеме из 5+ ключевых блоков:

1. **Первый экран** — заголовок, подзаголовок, УТП и кнопка СТА.
2. **Проблема / решение** — какую боль закрывает продукт.
3. **Как это работает / возможности** — функции и выгоды.
4. **Социальное доказательство** — отзывы, кейсы, цифры, логотипы.
5. **СТА-блок** — форма заявки, ссылка на Telegram, кнопка «Оставить заявку».
6. *(опционально)* — команда, тарифы, FAQ, контакты.
